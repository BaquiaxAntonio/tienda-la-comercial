# Sistema de Tienda — La Comercial

Sistema de inventario y facturación para una tienda de Quetzaltenango.
Proyecto de práctica del curso Programación Comercial — UMES.

## Módulos

- `inventario.py`: catálogo de productos y consultas de stock.
- `facturacion.py`: cálculo de subtotal, descuentos, IVA e impresión de factura.
- `descuentos.py`: reglas de descuento de la tienda.
- `reportes.py`: reportes de inventario.

## Cómo ejecutar

    python facturacion.py
    python reportes.py
